# 03 — 配音方案

> AI视频配音的正确姿势和所有踩过的坑。

## 三种配音方式对比

| 方式 | 积分 | 适用场景 | 坑 |
|------|------|---------|-----|
| 配音生成 | 免费 | 旁白、对白 | 下载入口不好找 |
| 对口型 | 免费 | 真人脸视频 | 水墨/暗黑风人脸模糊不适用 |
| AI配乐 | 5积分 | 背景音乐 | 仅音乐无语音 |

## 配音生成（推荐）

即梦首页 → 切到「配音生成」→ 选音色 → 填台词 → 生成。

```
一句台词 + 一个音色 = 一条语音文件（MP3/WAV）
```

### ⚠️ 经典案例：配音生成下载找不到

**症状**：点了生成，提示成功，但找不到下载按钮。

**原因**：配音生成页面不显示历史记录，生成完的音频不知道去哪了。

**解决**：暂时无解。建议生成后立即下载，别关页面。

### ⚠️ 经典案例：对口型不适合水墨风

**症状**：点对口型，画面人物没有明显嘴唇动作。

**原因**：对口型需要真人面部特征点检测，水墨/暗黑风画面人脸不够清晰。

**解决**：用配音生成替代。如果必须对口型，先用人脸照片生成数字人，再用对口型。

## AI配乐

即梦视频预览页 → 点「AI配乐」→ 5积分 → 根据画面/自定义。

支持：
- 根据画面配乐（自动匹配风格）
- 自定义AI配乐（指定风格/情绪）

## AI音效（免费）

即梦视频预览页 → 点「AI音效」→ 0积分。

适用于：鼓点、环境音、特殊音效。

## 完整配音流程（推荐）

1. 即梦出视频画面
2. 配音生成 → 文字转语音（免费）
3. AI配乐 → 背景音乐（5积分）
4. FFmpeg 合成：视频 + 语音 + 音乐
5. 检查音视频同步
