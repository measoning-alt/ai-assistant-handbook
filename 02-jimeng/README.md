# 02 - 即梦操作

> 从登录到出片，AI视频生成实战全流程。

## 登录
- 即梦 = 抖音体系，用抖音APP扫码登录
- 不是微信扫码！截图发给微信看不了
- 登录后会弹剪映绑定窗口，关掉即可

## 模型选择与定价

| 模型 | 积分/5s | 画质 | 适用 |
|------|---------|------|------|
| Seedance 2.0 VIP | 70 | 最高 | 正式大片 |
| Seedance 2.0 Fast VIP | 55 | 高 | 快速出片 |
| Seedance 1.5 Pro | 50 | 720P | 中等需求 |
| Seedance 1.0 Fast | 10 | 720P | 实验/省钱 |

## 提示词公式
```
主体 + 场景 + 动作 + 运镜 + 光影 + 画风 + 画质 + 负面词
```

## ⚠️ 经典案例：敏感词审核

**不要写**："夺心魄"、"控制别人"、"脱西装"——含这些词的提示词秒拒。

**解决方案**：用抽象描述代替具体动作和专有名词。如"女孩轻声低语了几句"代替具体台词。

## 配音方案
- 对口型需要真人脸，水墨/暗黑风不适用
- 配音生成：免费，文字转语音，下载音频后FFmpeg合成
- AI配乐：5积分，古风/暗黑风可选
- AI音效：免费

## 积分账本（典型案例）
80起始→4条江雪10积分/条=40→AI配乐5=45→充值69元得725→4条十日70/条=280→封面12×2=24→剩余234
